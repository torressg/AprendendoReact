# Learning React

My first steps with React. Each folder is a small Create React App project on one topic.

| Folder | Topic |
| --- | --- |
| `jsx` | JSX basics |
| `components` | Creating and reusing components, passing props |
| `rendercondicao` | Conditional rendering |
| `usestate` | State with `useState`, forms and lifting state between components |

## Running

```bash
cd <folder>
npm install
npm start
```
